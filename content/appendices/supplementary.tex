\chapter{Supplementary material}
Place material that supports the main text but would interrupt it here: full tables, questionnaires, derivations, and code listings.

\section{Page numbers}
The pages of an appendix continue the numbering of the main text. Add \texttt{appendixpages} to the class options to number each appendix on its own instead. The count then restarts at each appendix, and the footer reads ``Appendix A - Page 1''.
